## 2. The next move — REVIEW the design ZIP, then scope F0 (the M-frontend reskin)

### 2.1 What M-frontend is
A complete **reskin** of the existing warm cream-paper FE into a **premium, developer-grade** experience, with the **canvas EXPERIENCE emulating n8n's advanced AI-agent canvas** (the dual-axis feel; a model "satellite chip"; inline `+`/hover-delete authoring affordances; a high-density right config drawer). ### 2.2 The load-bearing STRATEGY: reskin onto the live skeleton (do NOT rebuild from the mockup)
A Claude Design export is a **showroom MOCKUP** — fake data, its own component structure, no real API calls, and none of our 165 vitest / React Flow wiring. **So we do NOT rebuild the FE from it.** We treat it as the **target LOOK** and **RESKIN the existing, running, tested app onto it, panel by panel**, keeping the app drivable + tests green after each slice. Analogy (used with the operator): a new paint job + interior on a car that's currently driving — keep the engine/transmission/wiring (the backend contract + state logic + tests), re-skin the body panel by panel, test-drive after each.

**The backend contract is the WALL.** Every reskin `/goal` ports the design's look + interactions onto the EXISTING files, extracting the design's tokens/CSS as reference — never swapping in the mockup's data layer or architecture. Hard rules: **no new endpoints** (only the ones in `frontend/src/lib/api.ts`); **`node.model` stays a single string**; **the model/Tools/Memory "satellites" stay VISUAL-only** (not real graph nodes/edges); **no new migration**.

### 2.5 The FE contract cheat-sheet (so you don't have to re-derive it — but DO spot-check `lib/api.ts`)
- **A node is ONE object**: `{id, role_name, kind, model (string), engine, prompt, position, config, status, iteration, invocations}`. `kind` ∈ `completion | agent | gate | terminal`; the FE vocabulary is `thinker | worker | gate | terminal` (maps to kind+engine). `capability` (thinker/worker) is PATCH-able. Gate/terminal have `model: null`, `prompt: null`.
- **Edges** = work/review flow with `conditions {when?, loop_limit?}`; FE roles `forward | branch | loop_back | escalation`. The reviewer loop-back is the bounded `{loop_limit:N}` dashed-arc (`rework` edge type).
- **Node CRUD endpoints exist**: `createTeamNode`, `updateTeamNode` (prompt/model/capability), `deleteTeamNode`, `createTeamEdge`, `deleteTeamEdge`, `saveTeamPositions`, `getTeamValidity`. Run/dashboard: `listRuns`, `getTeams`, `getTemplates`, `createTeam`, `deleteTeam`, `getTeamGraph`, `listProviders`/`addProvider`/`removeProvider`, `runTeam`, `getGraph`, `getRunStatus`, `getRunTasks`/`resolveTask`/`acknowledgeTask`/`cancelRun`, `inspectRepo`, `getDocument`/`addDocumentVersion`, `getRunEvents`, the A/B `startABRuns`/`getABComparison`. **Do not add endpoints.**
- **Real status set** (richer than 3): agent/thinker/worker `idle | running | done | failed | stopped`; gate `idle | awaiting | approved | stopped`; terminal `idle | shipped | stopped`; authoring flags invalid (red ring) / orphan (dimmed); a "round N" badge once `iteration ≥ 2`. (`lib/status.ts`.)
- **Real node taxonomy + shapes**: start/root node (the one no edge targets; capability locked to thinker) = a distinct "D"/launch shape; thinker/worker = rounded cards (role glyphs: PM=pen, Architect=drafting-compass, Engineer=terminal, Reviewer=clipboard); gate = shield checkpoint; terminal = ship(package)/stop(octagon) endpoint. **No separate n8n "trigger" concept** — the start node is the entry thinker.
- **React Flow scaffolding to RESTYLE (not rip out)**: one custom node type `agentNode` (dispatches by `kind` in `AgentNodeCard.tsx`); one custom edge type `rework` (the dashed arc); an 8-handle scheme (source+target on all 4 sides) with edges routed by geometry (`pickHandles`); `Background` dots, `Controls`, `MiniMap`. **Gotcha: React Flow's full a11y snapshot HANGS on the large canvas → use targeted `browser_evaluate` + screenshots, NOT a whole-tree snapshot.**
- **Styling idiom**: Tailwind v4 (`@import "tailwindcss"` + `@theme inline` bridging DS tokens to utilities like `bg-page`/`text-accent`/`font-display`) + a hand-written **CSS-variable design-token system** (`design-system/tokens/*.css`) + hand-written `.tv-*` component CSS (`index.css`) + per-node `.rf-node*`/`.rf-gate*`/`.rf-terminal*` CSS (`canvas.css`). Work in **Tailwind + CSS variables**, extend the tokens; no ad-hoc hex.
- **App shell**: `main.tsx → AuthGate` (root, gates login) → Landing (logged out) / Dashboard (post-login: teams · providers · runs) / `App.tsx` (the canvas: header + view-mode toggle [Single run | A/B compare] + TeamsRail/TasksDrawer + TeamCanvas + right SidePanel/TeamNodePanel). Authoring vs run = `runId === null`.
