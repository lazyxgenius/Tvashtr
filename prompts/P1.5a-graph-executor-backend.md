## The executor design (the crux — read carefully)

**5a generalizes the *walk* for the cyclic build/review subgraph; the PM phase + PRD gate + budget checkpoints + ship stay as fixed pre/post phases** (the proven P1.1/P1.2/P1.4b scaffolding). The deeper "every transition incl. PM and ship is an edge" uniform walk is **5b** (when gates become graph entities) — do NOT attempt it here.

`run_team` becomes:

```
@DBOS.workflow run_team(idea):
    run_id = DBOS.workflow_id
    graph  = load_graph_step(run_id)         # nodes + edges(with conditions); the PM node id + the subgraph entry (the agent node the PM's work edge targets)
    # ---- PM phase (unchanged behavior) ----
    open_invocation_step(run_id, pm_node_id, 1)
    pm = pm_step(run_id, idea, pm_model)
    close_invocation_step(run_id, pm_node_id, 1, status="done", outcome="prd_written")
    # ---- PRD gate (inlined, unchanged) ----        reject -> finalize_run_step("rejected"); return
    # ---- budget pre-engineer (inlined, unchanged) ----  over -> finalize_run_step("over_budget"); return
    workspace = engineer_setup_step(run_id)          # ONCE, before the loop
    # ---- the generic cyclic build/review sub-walk ----
    loop = run_review_loop(run_id, graph, workspace, pm["prd_text"])
    if loop["outcome"] == "over_budget":         finalize_run_step("over_budget"); return
    if loop["outcome"] == "failed":              mark_run_failed_step(...);        return
    if loop["outcome"] == "escalation_rejected": finalize_run_step("rejected");    return
    # outcome == "approved"  (happy approve, or escalation-approve = ship as-is)
    # ---- budget pre-ship (inlined, unchanged) ----  over -> finalize_run_step("over_budget"); return
    ship = ship_step(run_id, workspace); finalize_run_step("completed"); return {...}
```

`run_review_loop` is a **workflow-body helper** (NOT a `@DBOS.step` — it issues `wait_at_gate` and calls steps; like `enforce_budget`):

```
def run_review_loop(run_id, graph, workspace, prd_text) -> dict:
    max_iters = get_settings().max_review_iterations
    current = subgraph_entry_node_id              # the agent node the PM's work edge points to (the Engineer)
    iters_by_node = {}; reviewer_feedback = None
    while current is not None:
        node = graph_node(current); n = iters_by_node.get(current,0)+1; iters_by_node[current]=n
        if node.kind == "agent":
            if n > max_iters:                      # loop-cap guard BEFORE an over-limit agent iteration
                esc = wait_at_gate(run_id, topic=f"gate:{run_id}:review-escalation", kind="review_escalation",
                                   priority="high_blocker", blocking=True, title=…, description=…)
                if esc["resolution"] == "rejected": return {"outcome":"escalation_rejected"}
                return {"outcome":"approved"}       # ship the last good build as-is
            open_invocation_step(run_id, current, n)
            vkey = mint_vkey_step(run_id)
            eng  = engineer_run_step(run_id, prd_text, workspace, node.model, vkey, n, reviewer_feedback)
            delete_vkey_step(run_id, vkey)
            if eng["status"] == "over_budget":
                if eng["total_tokens"] or eng["cost_usd"]: persist_agent_cost_step(run_id, node.model, eng, n)
                close_invocation_step(run_id, current, n, "stopped", "over_budget"); return {"outcome":"over_budget"}
            if eng["status"] != "completed":
                close_invocation_step(run_id, current, n, "failed", None);            return {"outcome":"failed"}
            persist_agent_cost_step(run_id, node.model, eng, n)            # per-iteration key
            close_invocation_step(run_id, current, n, "done", "built")
            current = next_node(graph.edges, current, outcome=None)        # unconditional out-edge -> reviewer (or None for 2-node -> exit -> ship)
        elif node.kind == "completion":                                    # the Reviewer (the PM is in the PM phase, not here)
            open_invocation_step(run_id, current, n)
            verdict = reviewer_decide_step(run_id, node.model, n, prd_text, workspace)
            close_invocation_step(run_id, current, n, "done", verdict["outcome"])
            reviewer_feedback = verdict["reasons"]
            current = next_node(graph.edges, current, outcome=verdict["outcome"])
            if current is None: return {"outcome":"approved"}              # "approved" matches no loop-back edge -> exit
        else:
            return {"outcome":"approved"}                                  # defensive
    return {"outcome":"approved"}
```

`next_node(edges, source_id, outcome)` — **pure routing function** (importable + unit-tested):
- among edges with `source_node_id == source_id`: if `outcome is not None` and some edge's `conditions == {"when": outcome}`, return that target;
- else return the **unconditional** edge's target (`conditions is None`); else `None`.

**Why this handles both graphs:** the **2-node** team (PM→Engineer, no reviewer, no out-edge from the Engineer) → the sub-walk runs the agent once, `next_node` finds no out-edge → `None` → exit → ship. The **3-node** team → agent → reviewer → (loop-back on `changes_requested` | exit on `approved`). Same code; no role special-casing inside the walk.

**The Reviewer (`reviewer_decide_step`, recorded `@DBOS.step`):**
- **Forced harness (recorded, so crash-resume replays the same verdict):** if `TVASHTR_FORCE_REVISIONS=N` (read inside this step, like `gate_auto_resolution_step` reads its env), return `{"outcome":"changes_requested","reasons":"<forced>"}` while the reviewer iteration `n <= N`, else `{"outcome":"approved","reasons":None}`. **No LLM call, no cost** in forced mode.
- **Real mode (no env):** read the deliverable from the workspace (stdlib: list + read non-hidden files under `workspace`, cap total chars, skip `.git`), build a `CompletionRequest` instructing the Reviewer to judge the deliverable against the PRD and reply with a parseable verdict (`VERDICT: approved` | `VERDICT: changes_requested` + short reasons), `complete()` it, `record_cost(result, workflow_id=run_id, idempotency_key=f"{run_id}:reviewer-llm:{n}")`, parse `result.text`. Parse defensively: an unambiguous `changes_requested` → that; else default `approved` (the loop cap is the safety net). Real-mode judgment quality is **not** this prompt's concern (5c) — just correct + parseable.

**Per-node run-state (`AgentInvocation`):** `open_invocation_step` / `close_invocation_step`, recorded `@DBOS.step`s, idempotent on `(run_id, node_id, iteration)` (open = insert-or-noop with the IntegrityError-race catch like `open_gate_step`; close = update `status`/`outcome`/`ended_at`). New **boundary-clean module `backend/tvashtr/control_plane/invocations.py`** (imports only `dbos`/`sqlalchemy`/`tvashtr.{db,models}`).
