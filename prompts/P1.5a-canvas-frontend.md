## The design you are implementing

### A. Live status — flip the source (the core)

`deriveNodeStatus` collapses to a **thin read of the backend per-node `status`**, with a small overlay only for nodes that have **not run yet** (backend `idle`). New signature + logic:

```ts
export function deriveNodeStatus(
  backendStatus: string,            // the graph node's status: idle|running|done|failed|stopped
  run: RunRow | null,
  workflowStatus: string | null,
  predecessorDone: boolean,         // any incoming edge from a node whose backend status is "done"
): NodeStatus {
  // A node that completed stays done regardless of what happens downstream.
  if (backendStatus === "done") return "done";
  if (backendStatus === "failed") return "failed";
  if (backendStatus === "stopped") return "stopped";
  // backendStatus is "running" or "idle": let a terminal run/workflow override a stale in-flight
  // invocation (e.g. a no-key run leaves the PM "running" — the workflow ERROR'd — so read failed).
  const failed = run?.status === "failed" || WORKFLOW_FAILED.has(workflowStatus ?? "");
  if (run && RUN_STOPPED.has(run.status)) return "stopped";   // rejected/cancelled/over_budget → concluded short
  if (failed) return "failed";
  if (backendStatus === "running") return "running";
  // idle: not reached yet — the only place inference remains.
  if (run?.status === "awaiting_human" && predecessorDone) return "paused";  // blocked at a gate
  return "idle";
}
```

`predecessorDone` is computed **in the canvas** from the topology + raw backend statuses: a node has a done predecessor iff some edge targets it from a node whose **backend** status is `"done"`. (At the PRD gate: PM done, Engineer idle, Engineer's predecessor PM is done → Engineer `paused`; Reviewer's predecessor Engineer is idle → Reviewer `idle`. Correct.) `isRunTerminal` + `deriveOverall` are unchanged.

**Liveness wiring:** the per-node status now lives in the graph payload, which App fetches **once**. To animate it, **App must re-fetch the graph each poll.** Add `getGraph(runId)` to `pull`'s `Promise.all` and `setGraph(g)`. The canvas must **not** rebuild nodes every poll (that resets dragged positions): key the **build** effect on the **topology** (`graph?.run_id`) so it rebuilds only on a new run, and let the **status-refresh** effect (keyed on `[graph, run, workflowStatus]`) update each node's `data.status` + `data.iteration` in place by matching `graph.nodes` by `id`. (The existing code already separates these two effects and already `eslint-disable`s the build effect's deps — keep that shape.)
