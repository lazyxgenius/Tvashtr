# P1.3b part 3 — flip the default agent sandbox `local` → `docker`

## Objective
Now that forced-escape containment is proven (P1.3b part 2), flip the **global default** agent execution sandbox from `local` to `docker`, so the product's default run is containerized — while pinning the fast dev/test agent targets explicitly to `local` so they don't pay the container tax. This is a one-line config default change + its comment, four demo pins, and the config-sandbox test updated to match. **No product-logic change, no migration, no new dependency, no frontend change.**

## Context (where this fits + exact current state)

Tvashtr is a durable-workflow (DBOS) agent-orchestration backend. We're at Phase 1, step P1.3b part 3 — the final part of P1.3b. The Docker sandbox exists behind the `EngineAdapter` seam as a second adapter (`OpenHandsDockerAdapter`, engine name `"openhands-docker"`); the local path is `OpenHandsAdapter` (engine name `"openhands"`). The sandbox is selected **per process** by `Settings.agent_sandbox_mode` (env `TVASHTR_AGENT_SANDBOX`), read at run time in `engineer_run_step`. It is **not** a per-run API parameter.

How the mode resolves today — `backend/tvashtr/control_plane/team_run.py`, `engineer_run_step` (**DO NOT CHANGE this logic**):
```python
engine_name = (
    "openhands-docker" if get_settings().agent_sandbox_mode == "docker" else "openhands"
)
adapter = resolve_adapter(engine_name)  # lazy openhands import happens here
```
Flipping the *default value* of `agent_sandbox_mode` is therefore sufficient; this line and `engines/registry.py` are unchanged.

The current default — `backend/tvashtr/config.py`:
```python
    agent_sandbox_mode: Literal["local", "docker"] = Field(
        default="local",
        validation_alias=AliasChoices("TVASHTR_AGENT_SANDBOX", "agent_sandbox_mode"),
    )
```
(preceded by a comment block stating the default stays `local` and the flip is P1.3b — that comment is updated too).

**Consequence you must be aware of (it is correct — do NOT "fix" it):** the FastAPI lifespan in `backend/tvashtr/main.py` runs the agent-server orphan boot-sweep **only in docker mode**:
```python
if settings.agent_sandbox_mode == "docker":
    sweep_orphaned_agent_containers()
```
After the flip this runs on every startup that doesn't pin `local` (i.e. `make backend`, `make test`). It is exception-safe and a no-op when no agent-server containers exist / docker is unavailable, so it's harmless and is the intended docker-mode behavior. **`main.py` is do-NOT-touch** — the gating is already correct; the flip just turns it on. The pinned-local demos (Task 3) skip it.

Sandbox-mode landscape across make targets (verified against the Makefile + scripts):
- **Rides the default → MUST be pinned `local`:** `skeleton-run` (Makefile recipe, in-process TestClient), `skeleton-crash` (`scripts/skeleton_crash_demo.sh`, launches real uvicorns), `hitl-demo` (`scripts/hitl_demo.sh`), `budget-demo` (`scripts/budget_demo.sh`).
- **Already explicit docker (DO NOT TOUCH):** `skeleton-run-docker`, `skeleton-crash-docker` (`scripts/skeleton_crash_demo_docker.sh`).
- **Immune to the mode (DO NOT TOUCH):** `agent-smoke` (`scripts/smoke_agent.py` constructs `OpenHandsAdapter()` directly), `containment-smoke`/`containment-demo` (drive `OpenHandsDockerAdapter` directly), `smoke`, `crash-demo`.

Offline-suite safety (already verified — informs acceptance): no offline test runs `engineer_run_step`/the real agent (the run-path tests use probe workflows that exclude the agent step). The only test asserting the default is `tests/test_config_sandbox.py`. `make test` must stay **61**.
