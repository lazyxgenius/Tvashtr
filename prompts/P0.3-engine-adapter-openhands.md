# Claude Code Prompt — P0.3: Engine Adapter + OpenHands (local-dir workspace)
*(Tvashtr Phase 0, step 3 of 5 — issued 2026-06-15 by Tvashtr-2)*

## Objective
Introduce Tvashtr's **`EngineAdapter`** boundary — the uniform contract through which the Control Plane drives *any* coding-agent engine — and implement the **first concrete adapter over the OpenHands Software Agent SDK**. Prove it by having a single agent complete a trivial coding task in a **local-directory workspace**, with the engine's actions/observations streamed into a persisted **`RunEvent`** log. This is the "hands" of the walking skeleton: P0.2 gave us a metered brain and versioned documents; P0.3 gives us an agent that can actually touch a filesystem, behind a swappable interface.

## Context
- **Phase 0 walking skeleton, step 3 of 5. Prior steps are done and verified:**
  - **P0.1:** FastAPI + DBOS Transact in-process over Postgres; `hello_durable` proves crash-safe resume; `make crash-demo` is the harness; Alembic owns `public`, DBOS owns its `dbos` schema.
  - **P0.2:** the **Model Gateway** (`tvashtr/gateway/`, the only `litellm` importer) routes any `provider/model` and returns a Tvashtr-owned `CompletionResult`; the **document layer** (`Document` + immutable `DocumentVersion` chain) with idempotent writes; `make smoke` confirmed a live OpenRouter call (default `openrouter/meta-llama/llama-3.1-8b-instruct`).
- **Locked architecture decisions this step embodies:**
  - **D1 — OpenHands (via its Software Agent SDK) is the default engine.** But Tvashtr is **engine-agnostic by design**: engines sit behind an **adapter interface** so others (Claude Agent SDK, etc.) can be added later. **This step builds that interface *and* its first implementation** — the interface is the durable asset; OpenHands is the first thing plugged into it.
  - **Sandbox decision (operator, 2026-06-15): local-directory workspace first.** The OpenHands SDK can run an agent against either the local machine (a plain directory) or an ephemeral Docker/K8s workspace via its Agent Server — *the same `Conversation` interface either way*. We deliberately use **local-dir now** and defer Docker isolation to a dedicated later step, because P0.3's deliverable is the **adapter contract + event capture**, not isolation, and OpenHands' Docker integration on Apple Silicon is friction worth quarantining.
- **⚠️ Safety reality of local-dir mode (must be reflected in the code, not just understood):** a local-directory workspace means **the agent's shell/file tools execute as your user, on the real filesystem, with no isolation.** The adapter MUST confine the agent to a **dedicated throwaway working directory** and the mode MUST be **named unmistakably** (e.g. `LocalUnsandboxedWorkspace`, with a docstring/log line stating it is unsafe for untrusted tasks). Docker isolation is deferred, not forgotten — leave a clearly-marked extension seam.
- **Heads-up on this dependency (different in kind from P0.1/P0.2):** OpenHands is a heavier install and its first agent run may pull models/metadata and take noticeably longer than prior steps. That's expected, not a hang.
- **Deferred — do NOT build now:** Docker/K8s sandboxing; the Agent Server / remote workspace; the 2-node agent graph (that's P0.4); any UI (P0.5); multi-step or non-trivial coding tasks; confirmation-mode/human-approval policies. Keep the task trivial and the surface minimal.

## Tasks (in order)
1. **Dependencies.** Add the OpenHands SDK package(s) (pinned) to `backend/pyproject.toml`; `uv sync`. Record exact versions and the resolved import paths.

2. **The engine-adapter contract** — `backend/tvashtr/engines/base.py`:
   - Tvashtr-owned types (frozen dataclasses, matching the gateway's style): `AgentTask` (e.g. `instruction: str`, `workspace_dir: str`, optional `model: str | None`), `AgentRunResult` (e.g. `status: Literal["completed","failed"]`, `summary: str`, `events: list[EngineEvent]`, `files_changed: list[str]`, optional error), and `EngineEvent` (a normalized, engine-neutral record: `seq: int`, `kind: str` — e.g. `"action"`/`"observation"`/`"message"`/`"error"` — `payload: dict`, `ts`). These types must contain **no** engine-specific structures.
   - `EngineAdapter` (a `typing.Protocol` or ABC): the uniform contract. At minimum `name: str` and `run(task: AgentTask, on_event: Callable[[EngineEvent], None] | None = None) -> AgentRunResult`. The `on_event` callback is how the Control Plane will stream events live (used for `RunEvent` persistence and, later, the UI feed).

3. **The OpenHands adapter** — `backend/tvashtr/engines/openhands_adapter.py`:
   - `class OpenHandsAdapter(EngineAdapter)` with `name = "openhands"`. **The only module importing `openhands.*`.**
   - Implements `run(...)`: builds an OpenHands `LLM` from our `Settings` (default model + mapped key), constructs an `Agent` with the terminal + file-editor tools (prefer explicit tools over `get_default_agent` for control; `cli_mode`/no-browser as appropriate), creates a `Conversation` bound to the task's **local workspace directory**, sends the instruction, and runs it.
   - **Translate OpenHands events → our `EngineEvent`** via the verified callback/event seam, assigning monotonic `seq`, invoking `on_event` for each, and collecting them into the `AgentRunResult`. Map OpenHands action/observation/message/error types onto our `kind` values (document the mapping). Derive `files_changed` and a short `summary`/final status from the run.
   - **Workspace safety:** a small helper `make_local_workspace(run_id) -> str` creates a fresh dir under a gitignored root (e.g. `backend/.tvashtr_workspaces/<run_id>/`); the class/mode is named to signal it is **local + unsandboxed**. Add `.tvashtr_workspaces/` to `.gitignore`. Leave a `# TODO(P0.x): Docker-sandboxed workspace via OpenHands Agent Server` seam.

4. **`RunEvent` persistence** — model + migration + a tiny sink:
   - `RunEvent` model (`models.py`): `id`, `run_id` (text — a P0.3-local identifier; the real `Run` entity arrives in P0.4), `seq` (int), `kind` (text), `payload` (JSONB), `created_at`. Unique `(run_id, seq)` so re-emitting the same event is a no-op (idempotency-friendly, per the standing convention). Alembic migration `0003_run_events`.
   - A persistence sink (`backend/tvashtr/engines/run_event_sink.py`): given `run_id`, returns an `on_event` callback that writes each `EngineEvent` to `run_events`, insert-or-ignore on `(run_id, seq)` (same insert-or-return discipline as P0.2's metering/version writes).

5. **Spike endpoint + opt-in live runner** (mirror P0.2's smoke pattern — keep live agent execution OUT of the default test run):
   - `scripts/smoke_agent.py`, wired to `make agent-smoke`: **only if the provider key is set**, create a fresh local workspace, run `OpenHandsAdapter` on a trivial task — `"Create a file named hello.txt containing exactly: Hello from Tvashtr"` — persist events under a generated `run_id`, then print: the resolved status, the count + kinds of `EngineEvent`s captured, `files_changed`, and the **actual contents of the produced file** (proof the agent really acted). **Skip cleanly with a clear message if no key is present.**
   - Optionally expose `GET /api/spike/run-events/{run_id}` returning the persisted events for that run (useful for eyeballing; keep it small).

6. **Tests (no network, no live agent in the default suite):**
   - **Contract test with a fake adapter:** a `FakeEchoAdapter(EngineAdapter)` that emits a couple of canned `EngineEvent`s and returns a `completed` `AgentRunResult` — assert the Control-Plane-facing contract holds (events arrive via `on_event` in `seq` order; result shape correct). This proves the *interface* independently of OpenHands.
   - **RunEvent idempotency test:** push the same `(run_id, seq)` event twice through the sink → exactly one row. (Extends the standing at-least-once-safe convention to this layer.)
   - Keep these fully offline and deterministic.

7. **Regression + housekeeping.** Run the full `pytest` suite, `make crash-demo`, and `make smoke` — all must still pass (P0.1/P0.2 intact). `make lint` clean. Update `README.md`: the new `engines/` boundary, `RunEvent`, `make agent-smoke`, and a visible note that local-dir mode is unsandboxed/dev-only with Docker isolation planned. Commit in logical chunks.

## Acceptance criteria

- `make crash-demo` and `make smoke` still pass unchanged (P0.1/P0.2 intact).
- With a provider key set, `make agent-smoke` runs a real OpenHands agent in a local workspace and **produces `hello.txt` with the exact required contents**, printing the captured `EngineEvent`s (with kinds) and `files_changed`. The produced file genuinely exists in the run's workspace dir.
- **Only** `openhands_adapter.py` imports `openhands.*`; the Control Plane depends solely on `EngineAdapter` + Tvashtr engine types. The OpenHands `LLM` is configured from the existing `Settings` (no second key source).
