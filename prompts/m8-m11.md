## New rulings — final (apply them, don't ask again)

- **R17 Backup model on agent nodes (makes R2 true on the agent path).** Since M-unify every node runs the agent
  path. Its in-sandbox retry envelope is milestone B's `agent_num_retries=8` (OpenHands: 8 attempts, waits 8/16/32/
  64/120/120/120 s, 120 s per attempt), so a hanging model takes ~24 min to use up its tries and the 20-min stall
  sweep (R1) ends the step before R2's switch can happen; a 429 storm switches only after ~8 min. Ruling: **when the
  node has a usable backup** (the same rule the switch uses: `config.fallback_model`, else the account backup for its
  capability — a held key, a different model and a different provider), **the host sends R2's envelope: 3 attempts**
  (num_retries=3), so a hanging model reaches the switch in ~6.5 min and a busy one in under a minute. **With no
  backup, today's envelope stays** (there is nothing to switch to; R1's ceiling still ends a hung step at 20 min).
  The envelope is a HOST setting (`config.agent_llm_routing`, called by the three OpenHands adapters) — changing it is
  not patching the in-container agent-server. User sees: a hung model → Quiet → (Stalled for about a minute) →
  Activity "Switched to the backup model" and the run carries on, instead of "Failed: stopped responding" at 20 min.
- **R18 The agent drawer shows all six tabs.** Setup · Skills & tools · Memory · Runs · Tests · Docs are all visible
  at once in the 384 px drawer, labels wrapping as the Quality boards draw them (the `tabsT` row). The current
  sideways-scrolling row can hide **Docs**, an existing tab — that breaks base §2.2. The run view's drawer keeps its
  five tabs.
- **R19 A stopped run can be resumed.** R8 already lists stopped runs and the API allows it; add the entry point:
  the run view's callout for a stopped run gets **Resume from <step>** (same pick panel and confirm as a failed run).
  Stopped runs do NOT join Needs you (the person stopped it on purpose). The Stop dialog's last line changes from
  "You can’t resume a stopped run." to **"You can resume it later from the step it stopped at."** — draw both first
  (new Runs boards `Prob-Stopped` and `Prob-StopDialog`, built from `Prob-Failed` and the app's dialog).
- **R20 State words:** base §2.5's list gains **Not reached** (an ended run's agent it never got to). The app already
  used it before M2.
