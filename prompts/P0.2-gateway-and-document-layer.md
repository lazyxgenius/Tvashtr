# Claude Code Prompt — P0.2: Model Gateway (minimal) + Document Layer (minimal)
*(Tvashtr Phase 0, step 2 of 5 — issued 2026-06-10 by Tvashtr-2)*

## Objective
Add two foundational, provider-agnostic commodities behind clean boundaries: (1) a **Model Gateway** wrapping LiteLLM that routes a completion to *any* `provider/model` and records token usage + cost, and (2) a **versioned Document layer**. Prove both at once with a durable workflow that makes a **real, metered LLM call** and writes its output as a **versioned document** — and that survives a mid-run crash without duplicating either the cost record or the document version.

## Context
- This is step 2 of the Phase 0 walking skeleton. **P0.1 is done and verified:** a FastAPI backend runs DBOS Transact in-process over Postgres; a `hello_durable` workflow proves crash-safe resume; Alembic owns the app tables in `public`, DBOS owns its own `dbos` schema; `make crash-demo` is the resumability harness.
- Tvashtr's architecture has two relevant locked decisions:
  - **D9 — the Model Gateway is the single metering chokepoint, and must be provider-agnostic** (any model, any provider, the user's choice). LiteLLM is the locked tool. This step builds that boundary for real: the gateway accepts a free-form `provider/model` string and routes it. The default is **OpenRouter** (one key reaches Llama/Gemini/GPT/etc.) with an **ordered fallback list** so a down/ratelimited model transparently fails over.
  - **Work products are first-class versioned documents** — editable later by both humans and agents. This step builds the minimal store: a `Document` with an ordered chain of immutable `DocumentVersion`s.
- **A standing Control-Plane convention from P0.1 applies here:** DBOS guarantees a *completed* step is exactly-once, but a crash **mid-step** re-runs that step — so DB writes inside steps are *at-least-once*. Therefore **every side-effecting write in this step (CostRecord, DocumentVersion) must be idempotent**: deterministic key + upsert / "insert if not exists", so a re-run after a crash cannot double-write.
- **Deferred — do NOT build now:** any model catalog/registry/picker UI, virtual keys, budget *enforcement*, the LiteLLM proxy container, real-time streaming, the OpenHands engine adapter, the agent graph. Model identifiers are free-form pass-through strings in this step; selection UI comes in Phase 1. Keep the walking skeleton minimal.

## Constraints
- **Stack (unchanged, no substitutions):** Python 3.12 / uv; FastAPI; DBOS 2.23.0; SQLAlchemy 2 + Alembic; Postgres 16; pytest; ruff. Add **`litellm`** (pin the version you install) as the only significant new backend dependency. No frontend work in this step.
- **Verify, don't guess, the LiteLLM API.** Before coding, confirm against current LiteLLM docs/source: the `completion()` call signature; how `provider/model` routing works (esp. OpenRouter — typically `openrouter/<vendor>/<model>`); where token usage lives on the response (`response.usage.prompt_tokens` / `completion_tokens` / `total_tokens`); and how to compute cost (e.g. `litellm.completion_cost(completion_response=...)`, which may return 0 for free tiers). Use LiteLLM's **native fallbacks** mechanism if it cleanly supports an ordered model list; if not, implement a thin try-next loop yourself and note the choice. If reality differs from this sketch, follow reality and record it.
- **Gateway boundary must be clean and swappable.** All LiteLLM imports live *only* inside the gateway module — nothing else in the codebase imports `litellm` directly. The rest of the app calls `gateway.complete(...)` and gets back a small Tvashtr-owned result object (not a raw LiteLLM response). This is what lets the gateway be swapped or fronted by the proxy later.
- **Secrets:** provider keys come from env / `.env` only. Add commented slots to `.env.example` for `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `HUGGINGFACE_API_KEY`. Never commit a real key; never log a key.
- **Migrations:** new tables via a new Alembic migration in `public`. Do not touch DBOS's schema; do not point autogenerate at `dbos.*`.
- **Don't break P0.1.** `hello_durable`, its endpoints, and `make crash-demo` must still pass unchanged. Do not modify `PROJECTPLAN.md`, `HANDOVER.md`, or `prompts/`.

## Tasks (in order)
1. **Dependency + config.** Add `litellm` (pinned) to `backend/pyproject.toml`; `uv sync`. Extend `Settings` (config.py): `default_model: str = "openrouter/meta-llama/llama-3.1-8b-instruct"` (verify this is a currently valid, cheap/free OpenRouter slug; pick the closest valid one and note it), and `model_fallbacks: list[str]` (a couple of alternate slugs, e.g. another OpenRouter free/cheap model + one direct-provider model). Keep all model strings free-form — no enum.

2. **The Model Gateway** — `backend/tvashtr/gateway/` package:
   - `types.py`: Tvashtr-owned dataclasses/Pydantic models — `CompletionRequest` (model, messages, optional temperature/max_tokens) and `CompletionResult` (text, model_used, prompt_tokens, completion_tokens, total_tokens, cost_usd, raw_provider str, latency_ms). **Cost is recorded as token counts *and* computed USD** — counts are always meaningful even when free-tier cost is `0.0`.
   - `gateway.py`: `complete(request: CompletionRequest) -> CompletionResult`. Calls LiteLLM with the requested model, applying the ordered fallback list on failure (native LiteLLM fallbacks if clean, else a documented try-next loop). Extracts usage, computes cost, measures latency, returns a `CompletionResult`. This is the **only** module importing `litellm`. No DB writes in here — keep the gateway pure (call → result); persistence is the caller's job (the workflow step), which keeps metering idempotent per the convention.

3. **Persistence models** (`models.py`) + **migration**:
   - `CostRecord`: `id`, `workflow_id` (nullable — not every call is in a workflow), `idempotency_key` (text, **unique**), `model_requested`, `model_used`, `prompt_tokens`, `completion_tokens`, `total_tokens`, `cost_usd` (Numeric), `created_at`. The unique `idempotency_key` is what makes the write safe under at-least-once step execution.
   - `Document`: `id` (uuid), `title`, `doc_type` (free-form str, e.g. "prd"), `created_at`, `updated_at`.
   - `DocumentVersion`: `id` (uuid), `document_id` (FK), `version_no` (int), `content` (text — markdown), `created_by` (str, e.g. "agent:pm" / "human"), `idempotency_key` (text, **unique**), `created_at`. Unique constraint on `(document_id, version_no)`.
   - One Alembic migration creating all three. Keep `spike_hello_events` as-is.

4. **Document service** — `backend/tvashtr/documents/service.py`: small, transaction-safe helpers — `create_document(title, doc_type) -> Document`; `add_version(document_id, content, created_by, idempotency_key) -> DocumentVersion` (computes next `version_no`; **idempotent** — if a row with that `idempotency_key` already exists, return it rather than inserting a duplicate; handle the unique-violation race by catching it and re-reading); `get_document_with_versions(document_id)`; `list_documents()`.

5. **Metering helper** — `backend/tvashtr/gateway/metering.py`: `record_cost(result: CompletionResult, *, workflow_id: str | None, idempotency_key: str) -> CostRecord`, idempotent on `idempotency_key` (same insert-or-return pattern). This is the seam where a gateway result becomes a persisted, deduplicated cost row.

6. **The proof workflow** — `backend/tvashtr/control_plane/doc_writer.py`: a DBOS workflow `generate_doc(topic: str)` that:
   - **Step 1** (`llm_step`): build a `CompletionRequest` (a tiny prompt, e.g. "Write a 3-sentence mini-PRD for: {topic}") → `gateway.complete()` → `metering.record_cost(...)` using a **deterministic idempotency key derived from the DBOS step identity** (e.g. `f"{DBOS.workflow_id}:llm"`), so a crash-retry of this step reuses the same key. Return the generated text + the model used.
   - **Step 2** (`persist_step`): `create_document(...)` then `add_version(content=<text>, created_by="agent:doc_writer", idempotency_key=f"{DBOS.workflow_id}:v1")`. Return the `document_id`.
   - Use the durable-write convention throughout; the workflow returns `{document_id, model_used, total_tokens}`.

7. **API handles** (in `main.py`, or a small `routers/` module if cleaner — your call, keep it tidy):
   - `POST /api/spike/generate-doc` `{topic}` → starts `generate_doc`, returns `{workflow_id}`.
   - `GET /api/spike/generate-doc/{workflow_id}` → DBOS status + (if finished) the resulting document_id and the cost row for that workflow.
   - `GET /api/documents` → list; `GET /api/documents/{id}` → document + ordered versions.
   - `GET /api/costs?workflow_id=` → cost rows (all, or filtered).

8. **Idempotency test (critical, no live API).** A pytest that calls `add_version` and `record_cost` **twice with the same idempotency key** and asserts exactly one row exists each time and the same id is returned. This proves the at-least-once-safe convention directly, deterministically, with no network.

9. **Gateway test with a mocked LiteLLM.** Unit-test `gateway.complete()` by **monkeypatching the LiteLLM call** to return a canned response object (with a usage block) and asserting the `CompletionResult` is mapped correctly (tokens, cost, model_used). Also test the **fallback path**: first model raises, second succeeds, result reflects the second. No real network in the default test suite.

10. **Live smoke (opt-in, not in default test run).** A `scripts/smoke_gateway.py` that, **only if `OPENROUTER_API_KEY` is set**, makes one real `gateway.complete()` call against the default model and prints the `CompletionResult` (tokens + cost). It must **skip cleanly with a clear message if no key is present**. Wire `make smoke` to run it. This is how we confirm a real provider call works without coupling CI to a paid endpoint.

11. **Regression + housekeeping.** Run the full pytest suite **and** `make crash-demo` to confirm P0.1 still passes. `make lint` clean. Update `README.md` with the new endpoints, the provider-key setup (OpenRouter first), and `make smoke` / `make test`. Commit in logical chunks.

## Acceptance criteria
- `make test` is green and includes: the idempotency test (double-write → one row), the gateway mapping test, and the gateway fallback test — all **without network access**.
- `make crash-demo` still passes unchanged (P0.1 intact).
- With a real `OPENROUTER_API_KEY` in `.env`, `make smoke` makes one live completion and prints non-zero token counts (cost may legitimately be `0.0` on a free tier — that's expected and must not read as an error).
- The data model supports versioned documents: a document can hold an ordered chain of immutable versions; `(document_id, version_no)` is unique; re-adding a version with the same idempotency key does not create a duplicate.
- **Only** `gateway.py` imports `litellm`; the rest of the app depends on `gateway.complete()` + Tvashtr types.
- `ruff check` + `ruff format --check` clean. No real keys committed or logged. `PROJECTPLAN.md` / `HANDOVER.md` / `prompts/` untouched.
