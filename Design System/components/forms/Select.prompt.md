Styled native `<select>` with the same label/helper shell as Input. Pass `options` for convenience or `<option>` children.

```jsx
<Select label="Model" options={['Tvashtr Loom', 'Tvashtr Loom mini', 'Tvashtr Weave']} />
<Select label="Visibility" helper="Who can open this thread">
  <option>Just me</option>
  <option>My team</option>
</Select>
```
