# M4 — Team file — Implementation Plan

> Native execution (one implementer for the backend, one helper for the frontend, the brief's
> independent review). Contract: `docs/superpowers/plans/api/team-file.md`.

**Goal:** the whole team as one readable file — view / copy / download it from the canvas header, and
import a file from Home › New team as a NEW team after a check that changes nothing.

**Spec:** prompts/m1-m11.md §4 M4; Team Setup canvas › File-Panel, File-NewMenu, File-Check,
File-Imported, and the board added for M4: File-CheckError (a file that can't be read, naming its
line).

## Decisions (from the code map)
1. Format `tvashtr_team: 1` (contract): agents (id, name, based_on = built-in/<role> | custom/<role>,
   kind when not implied, model, backup model, file access, skills / tools / connectors / Domains by
   NAME, the per-node document and capability keys, instructions), gates, ends, routes, needs
   (connectors by provider key + github when the repo is on GitHub; secrets by NAME), layout.
2. Never a secret value, key, sign-in, token or memory: inline tool servers go out as their name and
   `${SECRET}` names only; free text gets `guardrails.mask_secrets`; a repo skill's URL loses its
   userinfo; the repo default is a hosted `owner/name`, never a server path.
3. Budget and repo default: new nullable `team_graphs.budget_usd` / `repo` (migration 0045); an export
   of a team without them uses its last run's.
4. YAML is rendered and parsed server-side (pyyaml, now declared); parsing composes the node tree so
   every error names its line (JSON parses the same way).
5. Import is a NEW library team (`template_key="import"`) in one transaction; names map to this
   account's Toolkit / connectors / Domains; what's missing becomes a fix (with the nodes that need it).
6. Not built (later milestones; no dead buttons): the boards' "v7 · saved", "version 7", "v1 ·
   imported", "Compare".

## Tests
`tests/test_team_file.py`: round trip of every template and of a rich team (bar the name), a
secret-bearing tool config never exporting a value, the check's cases from another account, import
with fixes, errors naming their line, owner scope, the last-run fallback, migration 0045.
`frontend/e2e/team-file.spec.ts` + `make team-file-e2e`.
